# CHK Universal Control 1.0.7

- Autorisation permanente LES FAITS depuis le panneau propriétaire, pour un connecteur et une installation précis.
- Création des rapports, association et dissociation des pièces existantes ; aucune suppression de rapport autorisée automatiquement.
- Révocation possible ; commandes en attente libérées uniquement sur confirmation distincte.
- Les autres applications et les données locales sont conservées.
