# Console CHK Universal

Ouvrir `/functions/v1/chk-universal-mcp/console` depuis un navigateur.

La console ne demande jamais la clé MCP utilisée par ChatGPT. Elle utilise une clé administrateur différente, stockée uniquement en mémoire du navigateur.

Fonctions : lister et activer/désactiver les applications, vérifier les outils de lecture, ajouter un adaptateur MCP désactivé par défaut.

Aucun droit d'écriture n'est activable dans la console : ajouter une application ne lui donne aucun contrôle sur les autres.

Le chatbot Qwen/Ollama n'est pas inclus dans l'hébergement Supabase Edge ; la console ne prétend pas fournir un modèle d'IA actif.
