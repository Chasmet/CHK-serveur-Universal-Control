# CHK Universal Control 1.0.8
- Consentement unique aux opérations courantes pendant la connexion OAuth ChatGPT, sur les applications autorisées, sans validation serveur par action.
- Pour les connexions déjà installées : option unique dans Connecteurs, révocable, sans autorisation répétée par application.
- LES FAITS : création des rapports et association/dissociation des pièces. Applications futures : capability automationSafe à déclarer à l'association.
- Les permissions Android, le cloisonnement des connecteurs et les protections des opérations sensibles restent en vigueur.
- Outils directs MCP agent_control_status, agent_observe, agent_input, agent_parallel utilisant le moteur CHK Android existant.
- Données, associations et identité Tailscale conservées. Aucune commande de bureau Windows n'est ajoutée.
