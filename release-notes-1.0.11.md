# CHK Universal Control 1.0.11

Ajoute CHK Sous-titres : 19 outils MCP, projets privés par connexion OAuth, import local via navigateur, transcription faster-whisper, alignement WhisperX facultatif, horodatage mot par mot, brouillons, corrections avec révisions, audit et exports SRT/VTT/TXT/JSON. Le serveur ne transmet pas le son brut au modèle ChatGPT. Python 3.10/3.11 et la première installation des moteurs sont nécessaires sur le PC. Aucun autre serveur, anciennes routes préservées. L'installation sur le PC et les essais sur les chansons doivent être effectués après publication.
