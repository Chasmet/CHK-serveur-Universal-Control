Autorisation Tailscale (une seule fois)

Une nouvelle machine virtuelle chk-universal est créée dans Tailscale. Elle a son propre HTTPS 443 et n'utilise pas le port 443 privé de PC-SALON.

OUVRIR L’AUTORISATION TAILSCALE

Connecte-toi avec ton compte Tailscale habituel et valide cette nouvelle machine. Reviens ensuite ici : le serveur vérifie la connexion automatiquement.

Connecter ChatGPT

L’URL MCP de l’identité indépendante sera affichée quand le HTTPS sera prêt. L’authentification est OAuth, pas « Sans authentification ».

Garde ton mot de passe privé. Il ne sera jamais ajouté à l'adresse MCP. Une installation existante conserve ses données et ses identifiants.

Mes applications

Pirate Warrior 2 : premier module local, commandes Godot à approuver dans le chat. D’autres applications peuvent être enregistrées sans modifier le MCP principal.
